# EcoCollecte Bangui

Citizen platform for reporting cleanliness issues, offered to the City Hall of Bangui.

## Links
- Live site: https://ecocollecte-mvp.vercel.app/
- API: https://cloud-based-web-system-design-eccollecte.onrender.com/health
- Rapport / Report (EN): docs/EcoCollecte_Report_EN.pdf

## Architecture
React + Vite (Vercel) → API Node/Express en Docker (Render) → MongoDB Atlas.
CI : GitHub Actions (tests du backend, build du frontend).
